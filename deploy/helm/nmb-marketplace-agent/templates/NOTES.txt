First steps
  1. Generate an encryption key (once) and put it in the Secret:
       python -m nmb_marketplace_agent.crypto generate
  2. Seal existing rows after upgrading from an unencrypted install:
       kubectl -n {{ .Release.Namespace }} exec deploy/{{ include "nmb.componentName" (dict "root" . "component" "admin-api") }} -- python -m nmb_marketplace_agent.crypto reencrypt
       kubectl -n {{ .Release.Namespace }} exec deploy/{{ include "nmb.componentName" (dict "root" . "component" "aegra") }} -- python -m nmb_marketplace_agent.checkpoint_store rewrap
     Check coverage first with `crypto status` / `checkpoint_store status`.
  3. Set encryption.required=true in production so a missing key fails startup.
  4. The dashboard image must be built with VITE_API_BASE pointing at the
     browser-facing admin API URL.

Backup, restore and key-rotation procedures: deploy/helm/BACKUP_RESTORE.md
