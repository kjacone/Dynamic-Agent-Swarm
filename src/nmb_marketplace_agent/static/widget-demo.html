Drop-in widget

The same assistant in your existing site. The browser only holds a publishable key.

<script src="/embed.js"
  data-key="pk_…"
  data-title="NMB Service Assistant"
  data-color="#0f766e"
  data-greeting="Hi! How can I help?"
  data-suggestions='["Why is my bill higher?","Check my ticket"]'
  data-config='{"USER_REF":"AMINA-0421"}'></script>
Copied
Add data-api when the gateway runs on another host. Both keys are optional: data-suggestions (or the agent's saved starting prompts) shows chips, and data-config or NMB.config("KEY", value) sends page values such as a signed-in customer's token to the agent's tools — never stored or shown in the chat.

Or keep your UI

For a CopilotKit-style copilot, install the React kit and point it at the same gateway.

npm i langgraph-kit

<LangGraphKitProvider gateway={{
  baseUrl, publishableKey, userId
}}>
  <ChatPopup title="NMB Assist" />
</LangGraphKitProvider>
The kit adds citations, human handoff, feedback, and useAgentReadable / useAgentTool.
